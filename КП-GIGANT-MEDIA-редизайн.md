## 2. Проблема текущего сайта

Текущий сайт (тёмная устаревшая подача) создаёт разрыв между реальным уровнем компании и тем, как её видит клиент онлайн.

| Проблема | Как это бьёт по бизнесу |
|---|---|
| Тёмный, шумный, «старый» визуал | Компания кажется менее современной, чем конкуренты |
| Слабый первый экран | Посетитель не понимает ценность за 5 секунд |
| Услуги как сухой каталог | Сложно выбрать направление → меньше целевых заявок |
| Слабые кейсы | B2B не видит доказательств результата |
| Нет ясного процесса | Страх сроков и хаоса |
| География и масштаб спрятаны | Не используется сильный аргумент «филиалы по стране» |
| Слабый путь к заявке | Лиды теряются на трении |

Сайт сейчас скорее «витрина прошлого», чем **B2B-инструмент продаж**.

## 5. Разбор по блокам сайта

### A. Header / навигация

**Что было:** перегруженное меню, слабый акцент на действие.  
**Что сделано:** sticky-шапка, логотип, понятное меню, заметная кнопка «Оставить заявку»; на мобильном — чистое меню.  
**Зачем:** пользователь всегда может перейти к нужному разделу или заявке.  
**Почему важно:** в B2B решают скорость и ясность.  
**Влияние:** меньше потери навигации, выше доходимость до формы.

### B. Hero (первый экран)

**Что было:** общий заголовок без жёсткого УТП и слабый визуальный фокус.  
**Что сделано:**

- короткий текст про полный цикл;  
- 2 CTA: «Рассчитать проект» / «Смотреть кейсы»;  
- живое фото производства;  
- чипы: 15+ лет · 1500 проектов/год · своё производство.  

**Зачем:** продать смысл компании за 5 секунд.  
**Почему важно:** первый экран = фильтр «свой/чужой» для корпоративного клиента.  
**Влияние:** рост вовлечения и кликов в услуги/кейсы/заявку.

**Что было:** карусель карточек без сильной продающей логики и без глубины.

- логика «каждая услуга = отдельный лендинг»;  
- готовые шаблоны страниц услуги (вывески, широкоформат) для масштабирования на остальные.

**Почему важно:** B2B приходит с конкретной задачей, а не «просто посмотреть».  
**Влияние:** более качественные лиды + база для SEO по услугам.

## 6. Дизайн-система и motion — что получает команда

- UI tokens (цвет, тип, радиусы, тени, отступы)

- Правила анимаций (easing, durations, что можно/нельзя)
- Шаблоны: главная / услуга / кейс
- Логика контента под B2B

Это снижает стоимость следующих обновлений и ускоряет запуск новых страниц услуг.

### Почему не «сделаем дешевле»

Дешевле почти всегда означает: меньше стратегии, слабее типографика и сетка, нет шаблонов, нет motion-системы, слабые кейсы, «красиво на desktop / плохо на mobile».  
Для производственной B2B-компании это прямой удар по доверию и цене контракта.

### Простая логика окупаемости

Один–два средних B2B-заказа с сайта окупают вложение в редизайн.  
Сильный сайт ускоряет решение клиента, усиливает позицию на тендерах и повышает конверсию входящего трафика.
