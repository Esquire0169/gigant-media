═══════════════════════════════════════
БЫЛО (текущий сайт):
- Тёмный, перегруженный, визуально устаревший стиль
- Слабый первый экран: не продаёт за 5 секунд

СТАЛО (редизайн):

- Адаптив под mobile

═══════════════════════════════════════
4. РАСПИШИ КАЖДЫЙ БЛОК САЙТА ОТДЕЛЬНО
═══════════════════════════════════════
Для КАЖДОГО блока используй единый шаблон:

### [Название блока]
- Что было
- Что сделано / как изменено
- Зачем (бизнес-задача)
- Почему это важно для B2B-клиента GIGANT MEDIA
- Как это влияет на конверсию / доверие / восприятие цены

Блоки (обязательно все):

A. Header / навигация
- Sticky header, логотип, меню, CTA «Оставить заявку»
- Прозрачность/белый фон при скролле
- Быстрый доступ к: О компании, Услуги, Клиенты, Кейсы, Процесс, Команда, Контакты

B. Hero (первый экран)
- Крупный заголовок-УТП: «Производим рекламу, которая работает»
- Короткий lead про полный цикл
- 2 CTA: «Рассчитать проект» / «Смотреть кейсы»
- Живое фото производства
- Чипы доверия: 15+ лет / 1500 проектов / своё производство
- Зачем: продажа за 5 секунд, снятие неопределённости

C. О компании
- Текст о 15+ годах, полном цикле, наружной рекламе, качестве
- Список филиалов по Узбекистану (география = масштаб и надёжность)
- Фото/визуалы
- Зачем: доказать, что это не «сайт-визитка», а федеральный по охвату производитель

D. Услуги (13 направлений)
- Карусель/карточки всех услуг с реальными фото
- Каждое направление — потенциальный отдельный лендинг
- Уже есть шаблоны: вывески, широкоформат (+ логика масштабирования на остальные)
- Зачем: клиент быстро находит нужную услугу; растёт SEO и глубина просмотра; выше качество лида

E. Нам доверяют / Кампании
- Две анимированные ленты с цветными логотипами клиентов на белых карточках
- Зачем: социальное доказательство за 3 секунды; бренды = цена и статус подрядчика

F. Кейсы
- Не «галерея картинок», а результаты: клиент / задача / решение / метрики
- Шаблон страницы кейса: проблема → подход → процесс → до/после → CTA
- Зачем: B2B покупает доказательства, не обещания

G. Процесс
- Этапы ведения проекта (понятный pipeline)
- Зачем: снижает страх «нас кинут / затянут сроки»; повышает готовность оставить заявку

H. Цифры (Numbers)
- 1500 проектов / 85 сотрудников / 15+ лет / 1500 м²
- Count-up анимация
- Зачем: масштаб и производственная мощь без длинного текста

I. Команда
- Живые портреты, роли, короткие trust-statements
- Зачем: humanize бренда; производство = люди, не абстрактный «завод»

J. Преимущества (Why us)
- Свой цех / индивидуальный подход / свой дизайн-отдел
- Зачем: закрыть возражения по цене, срокам и качеству

K. Отзывы
- Цитаты клиентов
- Зачем: усиление доверия перед формой

L. Promo-видео блок
- 45–60 сек visual summary сайта (без озвучки, титры на русском)
- Зачем: современный brand-moment; сайт ощущается как digital-продукт, а не «просто вёрстка»

M. Контакты / CTA форма
- Один сильный CTA-блок: консультация
- Поля: имя, телефон, язык, сообщение
- Телефоны и адрес
- Зачем: короткий путь к заявке; минимум трения

N. Footer
- Навигация, контакты, ссылки
- Зачем: ориентация + дожим на любом экране

O. Сквозная дизайн-система и motion
- Цвета, типографика Manrope, кнопки 56px pill, карточки, тени, spacing, radius
- Motion: reveal on scroll, hover-lift, parallax hero, marquee, count-up
- Адаптив: desktop / tablet / mobile
- Зачем: единый премиальный язык; дешевле поддерживать; выше perceived value

5. ПОЧЕМУ КУПИТЬ ИМЕННО У НАС
═══════════════════════════════════════
Раскрой убедительно (без воды):
1) Мы уже сделали концепцию и рабочий прототип редизайна под их бренд — не «продажа воздуха».
2) Сохранили бренд-акцент #ACD03A, но обновили визуальный язык до premium B2B.
3) Думаем не только «красиво», а как продающий инструмент: структура, CTA, доверие, путь заявки.

5) Учитываем рынок Узбекистана и реальный контент компании (услуги, филиалы, цифры, фото).
6) Срок/качество/прозрачность этапов (ниже в пакете).
7) Цена 6000$ соответствует рынку 5–6k и включает полный цикл, а не «макет в Figma без логики».
